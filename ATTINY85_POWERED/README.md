# ATtiny85 Powered Mini Oscilloscope – PCB Design

This repository contains the complete PCB design files for a **compact, low-cost mini oscilloscope** powered by the **ATtiny85 microcontroller**.  
The project is intended for **educational, experimental, and embedded systems learning purposes**.

---

## 📷 PCB Preview

![ATtiny85 Mini Oscilloscope PCB](https://github.com/MAATHES-THILAK-K/Mini-Oscilloscope-/blob/main/ATTINY85_POWERED/IMAGES/FRONT.png)

---

## 📌 Features

- ATtiny85-based minimal oscilloscope design  
- Compact single-board PCB  
- Designed using **KiCad**
- Low component count for easy fabrication
- Suitable for low-frequency signal visualization
- Ideal for students and hobbyists

---

## 📂 Folder Structure

- **GERBER/** – Manufacturing-ready Gerber files  
- **IMAGES/** – PCB renders and images  
- **3D MODEL/** – 3D visualization of the PCB  
- **BACKUPS/** – Design backups  
- **REPORT/** – Project documentation  
- **POS.zip** – Pick and Place files  
- **\*.kicad_\*** – KiCad project, schematic, and PCB layout files  

---

## 🛠 Tools Used

- KiCad (Schematic & PCB Design)
- ATtiny85 Microcontroller
